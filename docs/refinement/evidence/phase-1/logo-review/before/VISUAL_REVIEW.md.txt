## Observed issues and review hypotheses

Observed: C/Cent-s mark everywhere public, teal/navy palette, gradients, generous decorative hero/store surfaces, repeated borders/shadows, variable radii, small secondary text, home decoration before mobile main action, auth promotion before mobile form, duplicate store errors and headingless course error. Public mobile menu overlays page content as currently designed; no expanded state/Escape close. Login has visible keyboard outlines, real labels, LTR email/password and autofill; mobile menu measured 36×26px, below preferred 44×44 target. Reduced-motion auth animation computed 0.00001s.

Hypotheses: simplify home graphic, bring authentication task earlier, reduce repeated failure panels/nested containers, make the next action visually dominant. These are design proposals, not measured usability conclusions. Private dashboard eye flow remains source-based until local data is available.

No page received final visual acceptance. Scientific/document contents, dark mode, private flows and all rendered semantic status combinations need later evidence.
