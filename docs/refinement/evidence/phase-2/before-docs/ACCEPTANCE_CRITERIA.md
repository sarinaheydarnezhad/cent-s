## Cross-phase requirements

No protected architecture/protocol/data changes without separate approval; no automatic commits/push/deploy. No new production fixtures. Light/dark equivalent semantic hierarchy; contrast validation on actual rendered state and adjacent backgrounds. Keep visible data equivalents for progress, Persian/Latin/math direction, reduced-motion and meaningful labels. Preserve note drafts/revisions, server entitlement enforcement, request idempotency and callback cleanup. Do not hide essential functions to pass small-screen tests.

No blanket WCAG 2.2 AA claim from a color calculator or successful screenshot. Baseline/source metrics do not replace keyboard/dialog/screen-reader/actual private-state evaluation.
